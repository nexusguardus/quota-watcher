Quota Watcher is an open-source Cloudflare Worker + D1 that polls your API usage, estimates spend in real time, and alerts you before you hit your budget cap.

⟶ View on GitHub Free  ·  Open Source  ·  MIT

How it works

1

Connect

Drop in your OpenAI / Anthropic / Groq API key — it gets AES-256-GCM encrypted and stored in D1. We never see your key in plain text.

2

Monitor

A Cloudflare Cron trigger fires every 10 minutes, hits /v1/usage on each connected provider, and UPSERTs daily snapshots into D1.

3

Alert

Per-tick threshold evaluation catches spend anomalies before you exceed your cap. Alerts are deduplicated — one per threshold per day.

Architecture

Serverless end-to-end. No servers to maintain, no credentials in plain text.

# quota-watcher Worker — single process, three entry points # Runs on Cloudflare's edge, ~200ms cold start quota-watcher Worker ├─ HTTP routes ├── /api/health │ → { status: "healthy", env: "production", ts: <unix_s> } ├── /api/providers │ → GET list all connected providers ├── /api/providers/connect │ → POST { api_key, provider_name } → encrypt → D1 insert └── /api/providers/{id}/today → GET today's snapshot for one provider # Cron trigger — runs async, errors don't block HTTP Cron */10 * * * * └─→ handleScheduled() ├─ fetch providers from D1 ├─ decrypt credentials (AES-256-GCM, Web Crypto) ├─ poll /v1/usage per provider ├─ UPSERT snapshot row ├─ check budget thresholds → INSERT OR IGNORE alert └─ catch errors → log in D1, skip to next provider # Data layer D1 (quota_db) ├── providers # encrypted credentials + budget caps ├── usage_snapshots # per-day UPSERT rows ├── alert_events # deduplicated via UNIQUE constraint ├── model_pricing # per-model cost lookup (16 models seeded) ├── organizations └── org_members

Features

🔒 AES-256-GCM encryption

All API keys encrypted at rest via the Web Crypto API. Zero npm dependencies for crypto. Secret managed through wrangler secret.

📈 Fine-tune model pricing

Custom pricing in D1's model_pricing table. Fine-tune IDs automatically resolved to their base model before lookup via resolveModelId().

🔕 Deduplicated alerts

UNIQUE constraint on alert_events(provider_id, alert_type, alert_date) guarantees one alert per threshold per day — no notification spam.

🔄 Resilient polling

Per-provider try/catch with error logging. One provider's API outage doesn't cascade — the scheduler moves to the next connection and retries next tick.

⚡ Zero cold-reload

Runs on Cloudflare's edge network with sub-50ms cold starts. 100k requests/day on the free tier.

🪙 $0 to run

Cloudflare Workers free tier includes 100k requests/day. D1 storage 5 GB included. No credit card required.

Deploy in 5 minutes

One command from clone to live:

# 1 — Clone the repo git clone git@github.com:nexusguardus/quota-watcher.git cd quota-watcher # 2 — Install wrangler & login npm install -g wrangler@3 wrangler login # opens browser → authorize # 3 — Create D1 database (paste UUID into wrangler.toml) npx wrangler d1 create quota_db # 4 — Apply migrations npx wrangler d1 migrations apply quota_db --local npx wrangler d1 migrations apply quota_db --remote # 5 — Set encryption key openssl rand -hex 32 | wrangler secret put AES_GCM_KEY # 6 — Deploy to workers.dev + publish + cron trigger npx wrangler publish # Done — worker live at https://quota-watcher.omisrani19.workers.dev
